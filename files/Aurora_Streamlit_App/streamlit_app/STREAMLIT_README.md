# Aurora Dynamics — FP&A Decision Intelligence Dashboard (Streamlit)

Self-service Streamlit app covering:
- Executive overview (revenue/EBITDA trend, segment mix, margin trend)
- Actual vs Budget / Actual vs Forecast variance (interactive, filterable)
- Driver-based revenue model with live "what-if" sliders (ARPU, churn)
- ML vs statistical forecast model accuracy comparison + recursive forecast
- Base / Upside / Downside scenario planning
- 3-year long-range plan (scenario-flexed)
- NLP analysis of management commentary (sentiment, topic clusters, variance linkage)
- Raw data explorer with CSV download

## Run it locally

```bash
cd streamlit_app
pip install -r requirements.txt
streamlit run app.py
```

The app will open at `http://localhost:8501`. All data ships in the `data/`
subfolder (a SQLite database + derived CSVs produced by the FP&A pipeline
scripts), so no external database connection is required.

## Data lineage

`data/aurora_fpa.db` and the accompanying CSVs are generated by the pipeline
scripts in the parent project (`01_generate_data.py` → `03_forecast_variance_scenario.py`
→ `04_nlp_commentary.py`). Re-run those scripts and re-copy the `data/` folder
here to refresh the dashboard with new synthetic data or a different scenario
set.

## Notes

- This is a synthetic, illustrative dataset for "Aurora Dynamics Inc." — not
  real financial data.
- For a Power BI equivalent, import the CSVs in `data/` (or connect directly
  to `aurora_fpa.db` via an ODBC/SQLite connector) and rebuild the same pages
  as report tabs; the `sql/02_reconciliation.sql` views are portable to Power
  Query with minor date-function edits.
